# my-first-repo

我的第一个 GitHub 仓库。

## 这个仓库是做什么的

用来跑通 Git 的完整流程：本地写代码 → 提交存档 → 推送到 GitHub。
同时也作为前端学习的起点，里面是一个纯 HTML 页面，不依赖任何框架。

## Git 三板斧

```bash
git add .                    # 把改动标记为"待提交"
git commit -m "改动说明"      # 保存一次存档
git push                     # 推送到 GitHub
```

## 本地预览

直接双击 `index.html`，浏览器打开即可。

## 技术栈

- 纯 HTML + CSS，无框架依赖
