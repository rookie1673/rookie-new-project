从零跑通 Git 流程，前端学习的第一站

推送代码的三步

  1. 1 git add . — 把改动标记为待提交
  2. 2 git commit -m "说明" — 保存一次存档
  3. 3 git push — 推送到 GitHub
提示：推送前先 git pull 拉取远端最新内容，能避免大部分冲突。

关于这个页面

纯 HTML + CSS 写成，没有依赖任何框架。用浏览器直接打开就能看到效果， 适合作为前端入门的第一个练习。

接下来要学

  1. 1 分支：在平行线上改代码，不碰主线
  2. 2 Pull Request：审查过后再合并
  3. 3 解决冲突：两人改了同一处怎么办
